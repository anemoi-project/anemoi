# EVG-Project

Efficient Visual Generation (EVG) is an open-source inference framework for visual generation, with a focus on video generation and long-sequence visual generation models.

This repository is being initialized around the idea of combining efficient inference techniques with modern visual generation systems. The new technique included in this framework is Draft Visual Attention (DVA), a method intended to improve serving efficiency for long-sequence visual generation workloads.

## Project Goal

The goal of this project is to build a practical and extensible open-source inference engine for visual generation that can support:

- efficient video generation
- mixed-precision execution strategies
- inference-serving oriented optimizations


## Draft Attention Context

Draft Visual Attention (DVA) is one of the first techniques to be incorporated into this repository. The broader objective is not limited to a single algorithm, but to build a general inference engine. The idea is mainly come from the [Draft Attention](https://arxiv.org/abs/2505.14708).
